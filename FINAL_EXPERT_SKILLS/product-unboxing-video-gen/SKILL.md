# Product Unboxing Video Gen

## Overview
本技能专为真人出镜类产品开箱视频设计，自动生成逻辑连贯、体验真实的60秒沉浸式开箱视频。通过标准化的开箱叙事结构、真人全程一致性保障、卖点与镜头强绑定，确保产出的视频符合专业博主开箱质感，避免生硬剪辑和逻辑跳变。

## 标准Plan.json Schema
```json
{
  "demand": {
    "original_text": "用户原始需求全文 + 参考文本/旁白文案全文（必须）",
    "demand_list": ["结构化提取的产品卖点/开箱流程要点（必须，按**展示顺序**排序）"],
    "original_assets": ["用户提供的产品参考图、场景参考图路径（必须）"],
    "generated_assets": [
      "产品统一三视图（必须）",
      "博主形象参考图（必须，真人，三视图）",
      "场景风格参考图（必须）",
      "其他生成的辅助资产路径"
    ]
  },
  "shots": [
    {
      "shot_id": "镜头编号（必须，从1开始递增）",
      "description": "镜头详细描述，必须承接上一个镜头的开箱流程（必须）",
      "duration": "时长（秒，范围为4-15，必须）",
      "lines": "博主台词内容（必须，标注博主语气/情绪）",
      "subtitle": "字幕内容（可选，对应台词）",
      "shot_type": "连续镜头：与上一个镜头连续/切分镜头：与上一个镜头之间进行切镜（必须）",
      "require_assets": ["需要关联的资产ID（产品/博主/场景参考）"],
      "is_completed": "bool（必须，标记镜头是否生成完成）"
    }
  ]
}
```

## Workflow
### Step 0: 获取输出目录
使用`get-output-dir`技能获取输出目录保存中间文件和最终结果
初始化`plan.json`文件（记录`demand.original_text`）

### Step 1: 需求与资产盘点
- **理解用户需求**：提取视频时长、分辨率、风格要求、博主风格（数码博主/生活博主/测评博主）、配音要求
- **盘点用户资产**：收集用户提供的所有产品参考图、场景参考图、指定旁白文案，记录到`demand.original_assets`
- **提取文本素材**：收集用户提供的产品功能描述、卖点、指定台词，记录到`demand.original_text`
- **核心参数确认**：确认产品类型、开箱场景、是否需要真人出镜、是否有指定旁白文案
- **输出结构化要点列表**，从参考文本中提取核心产品卖点，按展示顺序记录到`demand.demand_list`

### Step 2: 全局一致性资产补全
- **盘点现有资产**：使用`vision-understanding`逐一理解用户提供素材的内容，对比plan.json需求评估是否足够
- 无论用户提供了什么素材，均续生成**全局一致性资产**：
  1. 产品统一三视图：基于用户提供的素材生成产品正/侧/背三视图，确保所有镜头中产品外观、配色、细节100%一致
  2. 博主形象参考图：真人出镜类必须生成博主三视图，明确外貌、服装、发型、人设，全程保持一致
  3. 场景风格参考图：生成开箱场景整体参考，明确桌面布置、光线、色调，全程保持一致
- 所有生成资产记录到`demand.generated_assets`，作为后续所有镜头生成的核心参考

### Step 3: 开箱脚本规划（生成plan.json）
- 基于叙事文案拆分镜头，每个镜头对应开箱流程的一个节点，镜头描述必须承接上一个镜头的动作，单镜头时长控制在4-15秒之间
- 为每个镜头规划：
  - `description`：明确描述当前开箱动作、画面内容，必须承接上一个镜头的结尾（如"刚拆开包装盒，伸手拿出产品主体"）
  - 时长、博主台词（标注语气情绪）、镜头类型
- 生成完整的`plan.json`文件，包含所有镜头的详细信息

### Step 4: 逐镜头视频生成
1. 读取最新`plan.json`全量内容并复述
2. 动态生成视频提示词，使用`video-gen`进行音画同出的视频生成：
  - 每个镜头生成时必须：
    - 所有镜头都应该引用**全局一致性资产**
    - 连续镜头必须额外引入上一个已生成的完整镜头视频作为参考，保证开箱动作衔接自然（如拆封动作的连贯性）
    - 如果包含台词/旁白：必须在**视频提示词内明确标注**说话人属性、音色、台词内容（但请声明无字幕）
    - 在生成第n+1个片段的时候，必须使用n个片段的音频作为参考[使用`split-audio`技能来分割音频], 以及第n个片段的视频，来保持角色，场景，音频等元素的高度一致，避免不协调的情况。并且你需要在prompt里写明: 参考[音频1]的音色, 背景音乐，保持音频等元素的高度一致，剧情连贯，禁止重复音频里说话的内容。参考[视频1]里的剧情和角色，背景等。禁止重复里面的剧情
    - 特写镜头必须明确标注需要突出的产品细节/参数
3. 生成完成后使用`vision-understanding`检查：
   - 产品外观、细节是否与参考图一致
   - 博主形象、服装是否全程一致
   - 开箱动作是否符合逻辑，衔接自然
   - 不符合要求的重新生成
4. 生成完成后更新shot状态到`plan.json`

### Step 5: 后期合成
1. 读取`plan.json`检查所有shot生成完成情况
2. 按使用`merge-video`技能和`change-fps`技能要求拼接并导出最终视频
3. 对最终视频使用`vision-understanding`技能进行理解检查质量，逐条检查`plan.json`的`demand.demand_list`是否完成，若不合格则进行对应返工或补充

## Dependent Sub-Skills
- `vision-understanding`：识别参考图内容、检查视频片段一致性
- `image-gen`：生成全局参考资产
- `video-gen`：生成（有声）视频片段
- `merge-video`：合并视频片段
- `change-fps`：视频帧率调整
- `resize-video-resolution`：视频分辨率调整
- `split-audio`：分离视频中的音频
- `audio-gen-v3`：生成博主配音(优先使用`video-gen`的原生音画同出生成能力，该技能仅作为质检不合格补充使用)
- `automatic-speech-recognition`：音频识别、为有人声视频添加台词字幕
- `get-output-dir`：获取输出目录保存最终文件
