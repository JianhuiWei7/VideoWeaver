# Product Video Demo 

## Overview
本技能以**文本约束为核心**，严格遵循"卖点优先、逻辑叙事"的广告生成理念，根据用户提供的产品描述、参考素材，自动生成60秒左右结构清晰、卖点突出的高质量产品演示视频。核心优势在于通过标准化的三段式广告叙事结构，确保1分钟内内容节奏合理、**逻辑连贯**，所有卖点都有明确的视觉呈现，避免素材堆砌和无意义炫技。

## 核心设计思想（五步法+CoT中间推导）
```
1. 理解需求 → 2. 盘点资产 → [CoT思维链：构建叙事逻辑线] → 3. 规划脚本（生成plan.json） → 4. 补全资产 → 5. 逐镜头生成
```
核心逻辑：**先有完整故事，再有镜头拆分**。所有环节以文本卖点为绝对核心，通过连贯的叙事逻辑串联卖点，再拆分为镜头，避免离散堆砌。

```json
{
  "demand": {
    "original_text": "用户原始需求全文 + 参考文本全文（必须）",
    "demand_list": ["结构化提取的卖点列表，按优先级从高到低排序（必须）"],
    "original_assets": ["用户提供的原始参考资产路径（可选）"],
    "generated_assets": [
      "产品统一参考图路径（必须）",
      "风格参考图路径（必须）",
      "其他生成的辅助资产路径"
    ]
  },
  "shots": [
    {
      "shot_id": "镜头编号（必须，从1开始递增）",
      "description": "镜头详细描述，必须明确对应哪个卖点、展示什么内容（必须）",
      "duration": "时长（秒，范围为4-15，必须）",
      "lines": "旁白内容（可选）",
      "subtitle": "字幕内容（可选）",
      "shot_type": "连续镜头：与上一个镜头连续/切分镜头：与上一个镜头之间进行切镜（必须）",
      "require_assets": ["需要关联的资产ID（可选）"],
      "is_completed": "bool（必须）"
    }
  ]
}
```

## Workflow

### Step 0: 获取输出目录
使用`get-output-dir`技能获取输出目录保存中间文件和最终结果

### Step 1: 需求与资产盘点
- **理解用户需求**：提取视频时长、分辨率、风格要求、配音需求、核心期望效果
- **提取文本素材**：收集用户提供的所有产品功能描述、参考文本，记录到`demand.original_text`
- **盘点用户资产**：收集用户提供的所有参考图片、视频、音频素材，记录到`demand.original_assets`
- **确认核心参数**：输出确认清单，包含核心卖点数量、预计镜头数、总时长范围

### Step 2: 卖点结构化提取
- 从参考文本和需求中提取核心卖点
- 为每个卖点分配展示顺序和建议展示时长
- 输出结构化卖点列表，记录到`demand.demand_list`，作为后续所有环节的唯一依据
- 自动校验：确认所有用户明确提到的卖点都被提取，无遗漏

### Step 2.5: 叙事逻辑构建（思维链CoT环节，内部推导不落地）
**有限尊重用户提供的参考文本/需求中的展示逻辑**
在此基础上
**核心：先构建完整的广告故事线，再拆分镜头，避免离散堆砌**
- 基于三段式结构，将结构化卖点列表串联成一篇连贯的广告叙事文案（类似广告旁白完整稿）
  - 开场部分：用一句话引入产品，抓注意力
  - 核心展示部分：按照"用户痛点→产品解决方案→功能优势→使用效果"的逻辑，自然串联所有卖点，卖点之间添加过渡语句，形成流畅的叙述
  - 结尾部分：总结核心优势，发出行动号召或品牌展示
- 推导逻辑：先想清楚"整个广告要讲一个什么故事"，再思考"这个故事可以拆分成哪几个画面"，而不是直接把卖点对应到镜头
- 确保叙事逻辑连贯，卖点出现顺序符合用户认知习惯，没有生硬跳转

### Step 3: 三段式脚本规划（生成plan.json）
**尽量遵循1分钟广告三段式叙事结构**：
| 剧情阶段 | 时长占比 | 内容要求 | 镜头类型 |
|---------|---------|---------|---------|
| 开场抓眼球 | 15% (~9s) | 展示产品核心外观/最震撼P0卖点，第一时间吸引注意力 | 切分镜头（全景/特写快速切换） |
| 核心卖点展示 | 70% (~42s) | 按优先级逐一展示核心卖点，每个卖点对应至少1个独立镜头，配高亮标注 | 连续/切分镜头 |
| 结尾收尾 | 15% (~9s) | 品牌展示/核心slogan/使用场景总结，留下深刻印象 | 切分镜头（全景收尾） |

- 基于连贯的叙事文案拆分镜头，每个镜头对应叙事文案中的一个片段
- 为每个镜头规划：
  - `description`：明确描述镜头内容，必须承接上一个镜头的结尾，开启当前镜头的内容，前后逻辑连贯，禁止孤立描述
  - 时长、旁白文案（直接对应叙事文案片段）、字幕内容、高亮标注要求、镜头类型
- 生成`plan.json`文件，包含所有镜
头的详细信息
- 前置校验：
  - 所有卖点都有对应镜头，无遗漏
  - 总时长符合用户要求，浮动±5秒
  - 三段式结构完整，节奏合理
  - 镜头描述前后逻辑连贯，符合叙事线，没有生硬跳转

### Step 4: 资产缺口评估与补全
- **盘点现有资产**：使用`vision-understanding`技能逐一理解用户提供素材的内容，对比plan.json的需求，评估用户提供的素材是否足够
- **生成全局一致性资产（必须）**：
  1. 产品统一参考图：基于用户提供的素材使用`image-gen`技能生成标准产品三视图，确保所有镜头产品外观一致（可能存在复数个产品，均需生成三视图）
  2. 风格参考图：生成视频整体视觉风格参考，明确色调、光影、质感、标注样式，但不要出现具体文字，仅作风格参考

### Step 5: 逐镜头视频生成
1. 读取最新`plan.json`全量内容并复述
2. 动态生成视频提示词，使用`video-gen`进行生成：
  - 每个镜头生成时必须引入：
    - 全局产品/风格参考资产
    - 必要时额外引入上一个镜头的尾帧，或镜头视频本身，保证画面衔接自然
    - 如果包含台词/旁白：必须在**视频提示词内明确标注**说话人属性、音色、台词内容
    - 如果要求展示文案：必须在**视频提示词内明确标注**文案内容与展现形式
    - 在生成第1+n段视频时, 需要将前段视频的音频作为参考音频传入, 以保持音频的一致性。
    - 使用 `split-audio` 技能来分离视频的音频, 然后将分离后的音频作为参考音频传入。
    - 并且要在prompt里面强调: "参考[音频1]的音色，节奏和背景音乐，保持一致"
3. 生成完成后使用`vision-understanding`检查镜头内容是否符合描述要求，不符合则重新生成
4. 生成完成后更新shot状态到`plan.json`

### Step 6: 后期合成
1. 读取`plan.json`检查所有shot生成完成情况
2. 逐条检查`plan.json`的`demand.demand_list`是否完成
3. 按要求拼接并导出最终视频
4. 对最终视频使用`vision-understanding`技能进行理解检查质量，若不合格则进行对应返工或补充

## Dependent Sub-Skills
- `vision-understanding`：识别用户提供的产品截图内容，提取产品特征
- `image-gen`：生成全局参考资产、镜头关键帧、处理产品截图添加标注
- `video-gen`：生成（有声）视频片段
- `merge-video`：合并视频片段，添加过渡动画
- `change-fps`：视频帧率调整
- `resize-video-resolution`：视频分辨率调整
- `split-audio`：分离视频中的音频
- `audio-gen`：生成配音旁白(优先使用`video-gen`的原生音画同出生成能力，该技能仅作为质检不合格补充使用)
- `automatic-speech-recognition`：音频识别、为有人声视频添加台词字幕
- `get-output-dir`：获取输出目录保存中间文件和最终结果
