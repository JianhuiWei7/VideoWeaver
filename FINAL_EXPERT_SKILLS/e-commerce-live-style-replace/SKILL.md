# 电商带货短视频主体/风格替换

## Overview
本技能实现电商带货短视频的自动化主体替换与风格重制，输入为原始参考视频（必选）、产品参考图（1~3张，必选）、文字需求描述（必选），输出与原视频时长完全一致、保留原视频的运镜节奏/镜头顺序/带货逻辑、替换产品主体或整体视觉风格的高质量电商短视频，适配抖音、小红书等主流内容电商平台。

## 核心要求
1. **时长一致性**：输出视频时长必须与输入参考视频完全相同，误差不超过0.1秒
2. **元素一致性**：多次出现的人物、场景、物体、品牌标识等元素必须高度统一，无逻辑冲突
3. **带货逻辑保留**：完全保留原视频的产品展示顺序、卖点讲解节奏、镜头切换逻辑
4. **画质要求**：默认输出4K分辨率、60帧，画面清晰通透，符合电商平台审美标准

## 工作流程

### Step 1: 输入资源校验与元数据提取
- 确认输入资源完整：原始参考视频、产品参考图、文字需求三者缺一不可
- 调用`get-video-metadata`技能提取原视频的时长、帧率、分辨率、总帧数，作为输出视频的硬性参数要求
- 调用`vision-understanding`技能分析参考图，提取产品的外观、颜色、材质、设计细节、包装特征等核心要素

### Step 2: 需求拆解与要素整合
- 从文字需求中提取：产品核心卖点、视觉风格要求、口播文案内容、平台适配规则
- 分析原视频的带货流程：镜头顺序、运镜方式、场景切换节奏、产品展示节点
- 使用`automatic-speech-recognition`技能识别原始视频的口播介绍内容, 然后输出`.srt`格式的文件 
- 然后根据输入的产品参考图来调整口播文案。
- 整合生成视频prompt，明确要求：1. 保留原视频所有运镜和镜头逻辑。2. 仅替换产品主体或者参考原视频的风格和节奏，以及口播文案:xxx, 3. 并且不要生成任何字幕。

### Step 3: 拆解与规划
- 将原参考视进行拆解，根据合适的时长进行拆解。拆解后的视频可以作为参考视频来进行视频的生成。
- 拆解后，视频时长应该保持在14秒左右。不宜过长或过短。拆解逻辑必须按照`.srt`文件的时间戳来拆，比如
```
1
00:00:00,250 --> 00:00:07,650
早上赶时间上班，我匆忙出门忘记买早餐，整个上午肚子饿的难受，又不好意思开口。

2
00:00:08,250 --> 00:00:13,160
同事默默注意到我的状态，悄悄把一份面包和牛奶放在我桌上，轻声说，看你没吃早饭，别饿坏肚子，快吃吧。

3
00:00:13,640 --> 00:00:21,440
没有夸张的关心，只有细微的体贴。

4
00:00:22,130 --> 00:00:25,770
真正的在意，从不用大声宣扬，全都藏在不起眼的细节里， quietly 温暖你的心。
```
那么，你可以将第一个和第二个片段合并在一起，拆解前13 (13.16四舍五入为13秒) 秒视频。
然后后面2个片段合并在一起，拆解后12 (25.770-13.640 = 12.130四舍五入为12秒)秒视频。拆解视频使用`trim-video`技能。拆解视频的起始点和结束点需要和`.srt`文件的时间戳一致。
拆解后的视频片段可以用作参考视频，来生成对应的视频片段。

最后你要将你的拆解逻辑和后面视频的生成逻辑输出到`plan.json`文件中并且indent=4. 你要将文件保存到`get-output-dir`获取的输出文件夹中。
```
[
  {
    "id": 1,
    "duration": 14.0,
    "prompt": "xxx[生成这一片段的内容，并且，你需要1. 强调, 音色, 语速, 需要参考原始视频的音频特征; 2.你需要输入适配到新产品的背景口播文案，格式为: 口播文案: 口播文案内容, 并且不要生成任何字幕，因为后期会增加字幕。]",
    "consistent_assets": ["xxx[这里选择用户提供的参考图片作为输入]"],
    "chosed_clips": ["xxx[选择拆解后到视频作为参考视频]"],
    "merged_audios_segments": ["1","2[.srt文件中，哪几个片段可以合并一起, 然后对视频进行拆解]", "3"]
  },
  {
    "id": 2,
    "duration": 12.0,
    "prompt": "",
    "consistent_assets": ["xxx"],
    "chosed_clips": ["xxx[选择拆解后到视频作为参考视频]"],
    "merged_audios_segments": ["xxx"] 
  }
]
```
### Step 4: 视频生成
- 调用`video-gen`技能，传入整合后的prompt和参考图、拆解后的原视频作为输入
- 生成参数强制要求：
  - 时长与原视频完全一致
  - 分辨率/帧率与原视频匹配（或升级为4K/60帧，除非用户另有要求）
  - 所有镜头中的产品、场景、人物前后高度一致
  - 突出产品卖点，符合电商带货的视觉表现力

### Step 5: 视频合并并加入字幕
- 调用`merge-video`技能，将生成的视频片段合并为一个视频文件
- 使用`automatic-speech-recognition`技能识别合并后的视频的口播介绍内容, 然后输出`.srt`格式的文件 然后再使用技能里的`embed_subtitles`功能加入字幕。所以，所有前面生成的视频都要强调不要任何字幕。
