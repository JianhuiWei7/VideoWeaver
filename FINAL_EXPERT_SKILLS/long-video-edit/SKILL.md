# Long Video Edit

## Overview

本技能用于长视频编辑任务，支持用户输入原始视频、文本指令、参考图片/音频等素材，输出与原始视频时长完全一致的编辑后视频。核心能力包括视频风格迁移、人物/物体替换、内容编辑，保证多镜头/分段编辑时人物、场景、物体等元素高度一致，剧情逻辑连贯。

## Core Requirements

1. **时长一致性**：输出视频时长必须与输入原始视频时长完全一致，不得缩短或延长
2. **元素一致性**：多次出现的人物、场景、物体、风格等元素必须保持高度一致，除非用户明确要求修改
3. **剧情连贯性**：编辑后的视频内容逻辑连贯，符合用户提供的文本指令要求
4. **保留原始内容**：用户未要求修改的内容（如音频、动作、背景等）必须完全保留，不得随意更改

## Workflow

### Step 1: 需求与素材分析
1. 接收用户输入：原始视频、文本编辑指令、参考图片/音频等素材
2. 调用`vision-understanding`分析原始视频内容：识别所有人物、场景、物体、风格、动作、音频等元素
3. 调用`vision-understanding`分析用户提供的参考素材：明确需要替换/修改的元素、目标风格、人物建模等
4. 确认用户需求：明确哪些内容需要修改，哪些内容需要保留。
**BAD PRACTICE**: 不要直接使用`vision-understanding`技能，来直接切分视频，判断剪辑的片段，而是要使用`video-shot-split`技能。具体如下

### Step 2: 视频拆分
1. 调用`video-shot-split`（设置 `--split=False`），输出一个包含各个镜头起始点和结束点的 `.csv` 文件。
2. 读取该 `.csv` 文件，按顺序将各个镜头进行合并。合并条件是：如果再合并一个镜头后时长小于 `video-gen` 单次能生成的最长时长，则继续合并，直到大于最长时长。以此确定各个分段的时间范围。
 - 如果有一个镜头长度就已经大于了 `video-gen` 单次能生成的最长时长，那么就直接将这个镜头拆分成多个片段，每个片段的时长都小于等于 `video-gen` 单次能生成的最长时长，并且大于等于 `video-gen` 单次能生成的最短时长。
3. 合并规划完成后，使用 `trim-video` 根据分段时间范围进行实际的视频分割。
**注意**：确保每个片段的时长都小于等于 `video-gen` 单次能生成的最长时长，并且大于等于 `video-gen` 单次能生成的最短时长。

### Step 3: 编辑计划制定
1. 调用`vision-understanding`理解每一个分割后的片段，并且为每个分割后的片段制定编辑计划：
   - 每个片段的编辑计划可能不一样，有可能片段不需要修改/编辑，你需要判断是否需要编辑, 有可能有的片段没有需要被编辑的元素
   - 首先，你要片段是否有要被修改的元素存在，或者这个片段是否需要被编辑。如果不需要被修改，那么require_edit为false。
   - 如果需要被修改，那么require_edit为true；然后，
      - 记录需要修改的元素：风格、人物、物体等
      - 标注需要使用的参考素材：图片、文本描述等
2. 输出`edit_plan.json`, 以indent=4格式输出到输出目录下，包含所有片段的编辑要求、时间范围、参考素材等信息。参考以下示例：输出目录可以使用 `get-output-dir` 获得。如果之前获取过那么就用之前的输出目录。不用重新执行。
```
[
   {
      "video_segment":"xxx[input the name of the video segment]",
      "require_edit": "true[input true if the video segment requires editing, otherwise false.]",
      "edit_plan": {
         "modify_elements": ["style"],
         "reference_images": ["ref1.jpg", "ref2.jpg"]
      },
   },
   {
      "video_segment":"xxx[input the name of the video segment]",
      "require_edit": "false[input true if the video segment requires editing, otherwise false.]",
      "edit_plan": {
         "modify_elements": ["None(You can input None if the video segment does not require editing.)`"],
         "reference_images": ["None"]
      },
   },
]
```
**注意**：必须要输出`edit_plan.json`文件，否则后续的编辑步骤会报错。
### Step 4: 逐段编辑视频
1. 根据`edit_plan.json`中的编辑计划，逐个处理每个镜头片段。确保已经输出了`edit_plan.json`文件。
2. 对每个镜头片段：
   - 如果需要被修改：
      - 输入当前片段的编辑的视频文件, 编辑的文本指令, 以及参考素材(图片等)
      - 如果是视频风格迁移, 可以先通过将当前片段的某一帧先提取出来转换成指定的风格, 然后再将转换后的帧作为参考图传入`video-gen`技能。并且在文本里强调, 只参考图片里的风格，其他元素不考虑。多个片段的风格迁移要保持一致，可以传入相同的参考图。
      - 文本编辑指令需要清晰，简洁，参考 `video-gen`中的提示词指南。并且要强调：其他元素不能被修改。
      - 基于原始片段、文本指令、参考素材，调用`video-gen`生成编辑后的片段
   - 如果不需要被修改：
      - 直接使用原始片段，最后在`merge-video`中合并。

### Step 5: 合并与输出
1. 调用`resize-video-resolution`和`change-fps`将所有编辑后的片段统一为原始视频的分辨率和帧率
2. 调用`merge-video`将所有片段合并为完整视频

## Best Practices

1. **一致性优先**：编辑过程中始终以元素一致性为首要要求，同一元素在所有镜头中必须保持相同的外观、风格、属性
2. **逐段校验**：每生成一个片段立即校验，避免后续合并后发现问题需要重新生成大量内容
3. **时长严格控制**：每个片段的时长必须与原始对应片段完全一致，确保总时长符合要求
4. **保留原始音频**：除非用户明确要求修改音频，否则直接复用原始视频的音频，避免音频不同步问题
5. **超时设置**：调用`video-gen`生成视频片段时，设置足够长的超时时间（不少于10分钟/片段），避免生成过程中被中断

## Dependent Sub-Skills

本技能依赖以下基础技能完成编辑任务，需要优先调用：
- `get-video-metadata`：获取原始视频的时长、分辨率、帧率等元数据
- `video-shot-split`：将长视频拆分为多个镜头片段，便于逐段编辑
- `extract-video-frame`：提取视频关键帧，用于参考和一致性校验
- `vision-understanding`：分析视频、图片内容，识别其中的人物、场景、物体等元素
- `image-gen`：生成编辑所需的参考图片、替换元素等素材
- `video-gen`：逐段生成编辑后的视频片段，支持图生视频、文本+参考视频生成
- `merge-video`：将编辑后的多个视频片段合并为完整长视频，保证过渡自然
- `trim-video`：调整视频片段时长，确保总时长与原始视频一致
- `resize-video-resolution`：统一所有视频片段的分辨率，与原始视频保持一致
- `change-fps`：统一所有视频片段的帧率，与原始视频保持一致
- `split-audio`：分离原始视频的音频，编辑后重新合并
- `get-output-dir`：获取输出目录，保存编辑过程中的中间文件和最终结果
