# Theme Video Gen

## Overview

本技能根据用户输入的主题或短文本，自动生成时长60秒、竖版9:16比例的短视频。生成过程中保证剧情连贯，所有重复出现的人物、场景、物体等元素保持高度一致性，同时匹配对应的背景音乐和视觉风格。

## 核心工作流
### 步骤1：需求解析与plan初始化

`plan.json` 标准Schema（必须生成）

```json
{
  "demand": {
    "original_text": "用户原始需求全文",
    "demand_list": ["逐字分析得到的需求要点列表"],
    "original_assets": ["用户提供的原始参考资产路径"],
    "generated_assets": ["生成的参考资产路径：风格图/人物/场景参考等"]
  },
  "shots": [
    {
      "shot_id": "镜头编号（必须）",
      "description": "镜头大致描述（必须）",
      "duration": "时长（秒，范围为4-15）（必须）",
      "lines": "台词/旁白内容(可留空，非必须)",
      "subtitle": "字幕内容(可留空，非必须)",
      "shot_type": "连续镜头/切分镜头（必须）",
      "require_assets": ["需要关联的资产ID(可留空，非必须)"],
      "is_completed": "bool（必须）"
    }
  ]
}
```
连续镜头指与上一个shot间画面连续，生成时需要用到上一个shot的资产（如尾帧或shot本身）
切分镜头指允许切换镜头
镜头总数建议4-6个之间
plan.json**不存储**最终视频生成提示词，提示词在生成阶段动态生成。
所有环节围绕`plan.json`展开，禁止脱离plan执行操作。

1. 逐字分析用户需求，提取结构化`demand_list`
2. 拆分镜头，初始化`shots`数组，重点在于规划shot的内容、时长、类型，暂不涉及具体提示词，需检查是否需要台词/旁白/字幕等
3. 生成初始plan.json，完成后校验schema完整性

### 步骤2：参考资产生成
1. 根据需求使用image-gen技能生成风格参考图、人物参考三视图等一致资产
2. 所有生成的资产路径实时更新到`plan.json`的`demand.generated_assets`中
3. 使用资产前需要对资产使用vision-understanding技能进行理解

### 步骤3：分段动态生成
每个镜头生成前必须执行：
1. 读取最新`plan.json`全量内容并复述
2. 动态生成视频提示词：
   - 如果是连续镜头：自动引入上一段尾帧作为参考
   - 如果是切分镜头：根据情况保持一致性，例如引用全局风格参考/对应人物/场景参考
   - 音频连续性：提取上一段视频中的10s左右的音乐片段作为参考保证音频一致
   - 如果包含台词/旁白：必须在视频提示词明确标注说话人属性、音色、台词内容
   - 如果要求文案：必须在视频提示词明确标注文案内容与展现形式
3. 生成完成后更新shot状态到`plan.json`

### 步骤4：拼接导出
1. 读取`plan.json`检查所有shot生成完成情况
2. 逐条检查`plan.json`的`demand.demand_list`是否完成
3. 按要求拼接并导出最终视频

## 基础依赖技能

本技能可能依赖的基础技能：
- get-output-dir：获取输出目录
- vision-understanding：视觉内容理解（任何视觉资产都应该先理解再使用）
- video-gen：视频生成
- image-gen：图片生成（用于一致资产准备）
- merge-video：视频拼接
- change-fps：帧率调整
- automatic-speech-recognition：音频识别、为有人声视频添加台词字幕
- audio-gen：语音合成
