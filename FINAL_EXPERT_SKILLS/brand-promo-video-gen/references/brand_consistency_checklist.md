# 品牌元素一致性检查清单

## 视觉元素检查
- [ ] Logo样式、配色、比例与参考图100%一致，无变形、色差
- [ ] 产品外观、颜色、细节与参考图完全匹配
- [ ] 品牌主色调使用符合规范，全片配色统一
- [ ] 人物形象、服装、妆容在不同场景中保持一致
- [ ] 场景的环境风格、光线风格保持统一
- [ ] 字体、图标等UI元素风格统一

## 内容逻辑检查
- [ ] 剧情连贯，符合品牌叙事主线
- [ ] 核心卖点出现次数符合要求，无遗漏
- [ ] Slogan出现位置、形式符合规范
- [ ] 旁白/台词内容与品牌介绍一致，无错误信息

## 技术参数检查
- [ ] 分辨率、帧率、画幅比例符合用户要求
- [ ] 转场流畅，无生硬跳转
- [ ] 音画同步，背景音乐节奏与画面匹配
- [ ] 无卡顿、掉帧、模糊等画质问题
