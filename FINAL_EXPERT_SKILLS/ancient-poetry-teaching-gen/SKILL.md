# Ancient Poetry Teaching Gen

## Overview
本技能用于生成古诗词教学动画视频

## 工作流（严格按顺序执行，禁止跳步）
**【极其重要】必须严格按照以下 1-6 的步骤顺序执行。前置步骤未完成并输出结果前，不允许提前执行后续步骤。**

### 步骤1：古诗输入与教学需求解析
#### 不要跳步
1. 读取用户提供的输入，常见输入包括：
2. 从文本中提取核心要素：
   - 古诗正文
   - 赏析说明
   - 教学目标
   - 用户指定的视频时长、分辨率、画幅、风格、字幕、配音和音频要求
   - 用户指定的镜头顺序、段落时长或必须出现的画面
4. 对 `参考图片` 调用 `vision-understanding`，提取：
   - 主要主体
   - 主体类型
   - 外观特征
   - 画面角度 / 局部细节
   - 使用场景或所在场景
   - 风格特征

### 步骤2：教学分镜规划
#### 不要跳步，注意分镜内容的丰富度
**【前置检查】：请确认步骤1已完成，已经提取古诗内容、教学需求、参考素材理解和硬性要求。**
1. 根据总时长和教学结构，将视频拆分为多个教学片段。每个片段时长不能超过 `video-gen` 技能的最大支持时长。尽量丰富每个shot的内容，若参考文本,用户需求较单薄，需要在遵守核心剧情的前提下，从台词、人物动作,场景细节，人物反应和情绪推进等方面补充内容，尽量使每个 shot 都有明确的信息量,避免片段内容空泛或重复。
2. 片段不要切得太碎。优先让每段承载一个清晰教学点，常见结构可以是：
   - 导入诗题和作者
   - 逐句讲解
   - 意象展开
   - 情绪收束
   - 总结回顾
3. 制定分镜计划，生成 `plan.json`，并保存到 `get-output-dir` 返回的输出目录下。
4. `plan.json` 中每个片段至少写清：
   - 对应诗句或教学点
   - 分镜内容和画面设计
   - 目标时长
   - 场景描述
   - 需要出现的主体、意象、道具或文字
   - 旁白文本、字幕文本、BGM 或音效要求
   - 需要使用的一致性资产
   - 是否需要承接上一段视频、尾帧或音频
5. prompt 重写时，必须把参考资料占位符按本次实际传入顺序重新排列，从 `[图1]` 开始，不要引用未传入的参考图。
6. 如果参考图之间存在关系，要在 prompt 中明确说明关系，例如 `[图1]` 提供人物风格，`[图2]` 提供江面场景，`[图3]` 提供诗句文字样式。
7. 旁白必须服务教学讲解。如果用户已给旁白，优先使用；如果没有，按古诗正文、赏析和教学需求补足。这里尽量每个shot都有对应的旁白
8. 生成连续镜头时，可以使用视频续写，但 prompt 中必须强调延续上一个视频的画风、节奏、音色和 BGM 风格，同时禁止重复上一段已经说过的旁白内容。
9. 分镜节奏应符合教学推进：导入 -> 讲解 -> 意象展开 -> 情感收束 -> 总结，不要写成无关联画面堆砌。


### 步骤3：古诗意象一致性资产生成
**【前置检查】：请确认步骤2已生成 `plan.json` 并保存到了输出目录。**
#### 不要跳步,调用image-gen 注意，这里需要参考参考图片的风格
1. 先做资产覆盖诊断：对照原始输入和 `plan.json`，判断现有参考素材是否足够支撑每个教学片段。
2. 提取 `plan.json` 中反复出现或关键的元素，尽可能生成丰富的一致性资产：
   - 诗句意象
   - 核心场景
   - 主要主体
   - 关键道具
   - 板书 / 诗句文字样式
   - 风格设定
   - 音效 / BGM 规则
3. 为每类元素生成对应的一致性资产：
   - 风格资产：整理统一的风格描述词，并可调用 `image-gen` 模型固定为 `gpt-image-2` 模型生成全局风格锚图。
   - 风格资产必须参考参考图片，参考[图1]的风格，生成xx的场景参考图
   - 角色：调用`gpt-image-2`使用`image-gen`，必须使用`gpt-image-2`模型。生成统一的角色的三视(正面、侧面、背面)形象图，并且保持纯白背景图, 可以在一张图中直接输出三视图
   - 这里如果参考图片有人物，参考参考图片生成三视图，如果没有，参考参考图片的风格
   - 场景意象：调用 `image-gen`，必须使用 `gpt-image-2` 模型。生成统一的场景设定图
      - 如果有多个核心场景，可以分别生成多个场景图。
      - 生成时需要参考图，例如：参考[图1]的色彩基调和场景质感，生成xxx的场景图
   - 道具意象：调用 `image-gen`，必须使用 `gpt-image-2` 模型。生成统一的道具图。
      - 道具图应尽量保持干净背景，方便后续片段重复引用。
      - 可以生成多个道具。高频出现或承担教学解释功能的道具优先生成。可以在一张图里面生成多个道具
   - 音效/音乐：提前规划统一的旁白音色、音效风格和背景音乐。
      - 后续片段默认延续同一旁白音色和 BGM 气质。
      - 局部器乐或音效变化只能作为叠加，不应让每段音频风格各自漂移。
4. 所有生成资产都必须保存到 `get-output-dir` 返回的输出目录下，供后续四宫格教学帧和视频生成复用。

### 步骤4：分段四宫格教学帧生成
#### 不要跳步, 每个shot都要生成对应的四宫格
**【前置检查】：请确认步骤3中所有必要的一致性资产已生成并保存。如果未完成，请立刻停止当前步骤，返回步骤3。**
1. 从 `plan.json` 中读取每个教学片段，为每个片段生成对应的四宫格教学帧。
2. 四宫格教学帧用于展示该片段的整体画面走向，不是最终视频，也不是额外的分镜 JSON。
prompt写上：生成一张4宫格图片，展示这个shot的整体走向, 从左上角到右下角分别是1-4, 每个格子上面都需要有数字+简短文本介绍。参考[图1]的xxx, [图2]的xxx, [图3]的xxx, [图4]的上一个片段的四宫格。要强调衔接上一个四宫格的第4张照片继续。新的四宫格要避免剧情重复。然后写上这个片段的剧本剧情，并且强调一下每个格子大致的主要内容。
3. 每个片段的四宫格生成时，需要传入：
   - 当前片段相关的所有一致性资产
   - 原始参考图或参考视频关键帧
   - 上一个片段的四宫格教学帧（第一个片段除外）
5. 每个片段的四宫格教学帧都必须保存到输出目录，作为该片段 `video-gen` 的核心视觉参考。

### 步骤5：分段生成教学动画
#### 不要跳步
**【前置检查】：请确认步骤4中每个片段的四宫格教学帧已生成完毕。如果未完成，请立刻停止当前步骤，返回步骤4。**

1. 按照 `plan.json` 逐段生成视频。
2. 每段生成时，必须传入：
   - 当前片段的四宫格教学帧
   - 当前片段相关的一致性资产
   - 当前片段需要的原始参考素材
   - 从第 `n+1` 段开始，传入第 `n` 段的音频作为连续性参考
3. 从第 `n+1` 段开始，如果需要音频连续性，必须先用 `split-audio` 从上一段视频中拆出音频，并在 prompt 中明确：
   - 参考上一段音频的旁白音色
   - 参考上一段音频的 BGM 气质
   - 保持教学语气和旁白节奏一致
   - 禁止重复上一段已经说过的旁白内容和背景音乐段落
   - 在场景过渡时，可以在prompt里面写明，从xx场景过渡到xx场景
   - 在prompt里面需要写出这个shot的完整的旁白口播文案
5. 每段生成超时设置要足够长，避免中途失败。


### 步骤6：视频合并与后期处理
#### 不要跳步
**【前置检查】：请确认步骤5所有分段视频均已成功生成。如果还有缺失，立刻返回步骤5继续生成。**

1. 使用 `merge-video` 将所有片段合并为完整视频，保证片段衔接流畅。
2. 根据用户需求添加或整理字幕、诗句文字、板书、音效和背景音乐。
3. 如果最终分辨率或 fps 不满足用户要求，使用 `resize-video-resolution` 或 `change-fps` 调整。
4. 导出最终成片，保存到 `get-output-dir` 返回的输出目录下。

## 依赖子技能
本技能依赖以下基础技能，执行过程中需直接调用：
- `get-output-dir`：获取任务输出目录路径
- `vision-understanding`：理解参考图片/视频，并检查生成结果是否符合要求
- `extract-video-frame`：从参考视频或上一段视频中抽取关键帧
- `image-gen`：生成古诗意象资产、文字资产和四宫格教学帧
- `video-gen`：生成单段教学动画视频
- `split-audio`：拆分上一段音频作为连续性参考
- `merge-video`：合并多个视频片段
- `trim-video`：必要时裁剪调整视频片段时长
- `resize-video-resolution`：调整最终分辨率
- `change-fps`：调整最终帧率

## 注意事项
1. 古诗教学理解是核心：不能只把诗句原文直接塞进视频 prompt。
2. 资产一致性是核心：同一人物、同一场景、同一道具、同一文字样式在不同片段中必须保持一致。
3. 意象资产要尽可能丰富，尤其在参考素材较少时，要主动补齐场景、主体、道具、氛围和桥接资产。
4. 分段视频必须连续，不能每段都像独立新视频。
5. 后续段落默认要显式处理音频连续性，不得让旁白音色、BGM 气质和教学节奏各自漂移。
6. 长视频生成需合理拆分片段，每个片段时长不超过 `video-gen` 技能的最大支持长度。
7. 所有输出都必须保存在 `get-output-dir` 返回的输出目录下。
