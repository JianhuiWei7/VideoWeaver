# Output Rubric 评测方法 (O2-O8)

> `output-eval/SKILL.md` 的展开。统一评分: `1`=无明显问题 / `0.5`=有瑕疵 / `0`=明显问题。
> 多子项时取最差档作为该指标得分,不做加权。所有判定优先复用 `cache/` 产物。

---

## O1 · 通过率
不打分,不填写。

---

## O2 · 需求达成度

**思路**: 把 `input_materials.需求 + 参考文本` 拆成简单清单 → 逐项判断 → 取最差档。

### 拆需求 (一次 LLM 调用)
按类型分桶:
- **数值类**: 时长 / 分辨率 / 帧率 / 镜头数 → 走 `meta.json` / `shots.json` 直接比对 
- **内容类**: 旁白文本 / 视觉元素 / 场景 / BGM 风格 → 查 `overview.json` + `transcript.txt`;若 cache 信息不足,再调一次 `vision-understanding(cache/grid_overview.jpg, prompt)` 补判

### 判分
- 全部命中 → **1**
- 有 1-2 项明显偏差 (例如时长差 15%、某个视觉元素缺失) → **0.5**
- 关键需求未达成 (旁白完全对不上、核心场景缺失) → **0**

## O3 · 参考忠实度

### 适用判断
若 `input_materials.参考图片 == [] and 参考音频 == []`:
**O3 = 1**,反馈留空。

### 三类路由

每条参考素材先按类型分桶,再走对应 prompt。**类型判定**(一次轻量 LLM 调用,或直接看文件名后缀 + `input_materials` 的字段名):

| 类型 | 路由依据 | 工具 |
|------|----------|------|
| `character` (人物参考) | 图片里主体明显是角色 / 文件名含人名 | `vision-understanding` + `cache/grid_overview.jpg` |
| `background` (背景/场景参考) | 图片里主体是环境/房间/户外 | `vision-understanding` + `cache/bg_grid.jpg` |
| `audio` (参考音频) | 输入是音频文件 (`input_materials.参考音频`) | `audio-understanding` + `cache/audio.mp3` |

#### A. character (人物参考)

```
vision-understanding([参考图_1, ..., 参考图_N, cache/grid_overview.jpg], prompt)
```

```
前 N 张是参考角色,最后 1 张是视频全片网格总览 (每格 2s,左上角 [N] 序号,左下角 mm:ss)。
回答:
1. 每个参考角色在视频中是否出现? 出现在哪几格?
2. 出现时,五官 / 发型 / 发色 / 服装 / 配饰 / 体型 与参考是否一致?
3. 列出明显不一致点。

输出 JSON: {"references":[{"ref_idx":1,"appeared":true,"cells":[3,7,12],"faithfulness":1/0.5/0,"issues":["..."]}, ...]}
```

#### B. background (背景/场景参考)

```
vision-understanding([参考图_1, ..., 参考图_N, cache/bg_grid.jpg], prompt)
```

```
前 N 张是参考的"场景/背景"。最后 1 张是视频背景关键帧网格 (3×2,已聚焦环境)。

请【完全忽略画面中的角色 / 人物】,只关注:房间结构 / 家具布局 / 墙面装饰 / 窗户 / 灯光 / 户外元素。

回答:
1. 每张参考背景是否出现在视频中?对应哪几格?
2. 出现时,环境关键元素 (3-5 个) 是否与参考一致?
3. 列出明显不一致点。

输出 JSON: {"references":[{"ref_idx":1,"appeared":true,"cells":[2,5],"faithfulness":1/0.5/0,"issues":["..."]}, ...]}
```

#### C. audio (参考音频)

```
audio-understanding([参考音频_1, ..., 参考音频_N, cache/audio.mp3], prompt)
```

```
前 N 段是参考音频 (角色音色 / BGM 风格等),最后 1 段是视频的完整音轨。
回答:
1. 每段参考的音色 / 风格是否在视频中出现? 出现在大概什么时段 (mm:ss)?
2. 出现时,音色 / 节奏 / 情绪是否与参考一致?
3. 列出明显不一致点。

输出 JSON: {"references":[{"ref_idx":1,"appeared":true,"t_ranges":["00:08-00:14"],"faithfulness":1/0.5/0,"issues":["..."]}, ...]}
```

### 判分
**取所有参考素材**(三类合并)的 `faithfulness` **最差档**作为 O3。

## O4 · 视觉一致性

**两路分开判,两次 VLM 调用**:
- 人物用 `cache/shot_grid.jpg` (主体占画面大,网格能看清)
- 背景用 `cache/bg_grid.jpg` (镜头全网格里每格被压太小,背景细节看不清,且 VLM 主体偏置会忽略背景)

### A. 人物一致性

```
vision-understanding(cache/shot_grid.jpg, prompt)
```

```
以下是同一视频按时间排序的镜头首帧,左上角数字是 shot 编号。
排除剧情合理变化 (成长、换装情节),评估:
1. 主体身份是否在不同镜头中一致 (五官/发型/发色/体型)?
2. 服装/配饰/道具是否一致?
列出具体不一致点 (shot 编号 + 描述)。
输出 JSON: {"subject":0/0.5/1, "wardrobe":0/0.5/1, "issues":[...]}
```

### B. 背景一致性

```
vision-understanding(cache/bg_grid.jpg, prompt)
```

```
以下是 6 张关键帧 (3×2),左上角数字是序号。

请【完全忽略画面中的角色 / 人物】,只关注背景环境:
- 房间结构 / 家具布局 / 墙面装饰 / 窗户 / 灯光色温
- 户外元素 (建筑/植物/天空)

回答:
1. 给每张一个 location 标签 (如 "客厅A" / "图书馆" / "街机厅")。
2. 相邻帧的背景变化是剧情合理切换 (换场景) 还是同一场景被画成了不同样子 (穿帮)?
3. 列出所有"应该是同一场景但背景不一致"的帧对 (用序号引用)。

输出 JSON: {"locations":["客厅A","客厅A","图书馆",...], "background_inconsistencies":[{"frames":[1,4],"desc":"..."}], "score":0/0.5/1}
```

### 判分
取人物 / 背景里**最差**那档作为 O4:
- 全部一致(或不一致都属剧情合理切换) → **1**
- 局部偏差(单处服装小变化 / 同场景背景细节略飘) → **0.5**
- 人物子项任一为 0,或背景有明显穿帮 → **0**

## O5 · 音频一致性

**单次 audio-understanding 调用** + ffprobe 兜底。

### 主调用

```
audio-understanding(cache/audio.mp3, prompt)
```

```
这是一整段视频的音轨 (人声 + BGM 混合)。请综合判断:

1. **角色音色一致性**: 是否同一说话人 (或多角色)? 同一角色跨段音色是否一致 (音高/音色/口音/语速)?
   若多说话人,按角色 (A/B/C) 标注。是否有明显 TTS 切换、变调、断点、噪音衔接?
2. **BGM 风格一致性**: 全片 BGM 的乐器/节奏/情绪是否一致? 若不一致,是剧情合理切换还是突兀跳变?
3. **音频拼接痕迹**: 有无可听见的 cut/拼接/失真?

输出 JSON: {
  "speaker_consistency": 0/0.5/1,
  "bgm_consistency": 0/0.5/1,
  "splicing_artifacts": [{"t_sec":12.3,"desc":"..."}],
  "long_silence": [{"t_sec":42.0,"duration":5.0}],
  "overall": 0/0.5/1
}
```

### ffprobe 兜底 (确定性,不交给 LLM)
- `ffprobe cache/audio.mp3` 检查音频时长 vs 视频时长 (abs diff < 0.5s)
- 无音轨 → O5 直接判 **0** (硬卡)

### 判分
取 LLM `overall` 与硬卡条件的最差档。

### 可选 escalation (LLM 听感不可靠时)
若 `speaker_consistency` 落在 0.5 灰区且需要确定性数值,可:
1. 调 `audio-vocal-separate` 把 `audio.mp3` 拆出 `vocals.wav`(去 BGM)
2. 按 `shots.json` 切出 `voice_shots/shot_XX.wav`
3. 调 `voiceprint-compare --mode matrix` 算 N×N 余弦相似度
4. 若 cluster intra 均值 ≥ 0.85 → 强一致;< 0.65 → 强不一致;两者冲突时标 `confidence=低`,留人工复核

## O6 · 物理 / 常识异常

### 单次调用

```
vision-understanding([cache/grid_overview.jpg, cache/bg_grid.jpg], prompt)
```

```
第 1 张是视频全片网格总览 (每 2s 一格),第 2 张是 6 张背景关键帧。

请扫描所有"非真实异常":
- 物体穿模、肢体扭曲、面部崩坏
- 画面闪烁、卡帧、纯色帧
- 物理违反 (漂浮/穿透/突现/重力错误)
- 文字/logo 乱码或扭曲
- 镜头切换突变、同一场景人数错乱
- 背景完全不符合常理
- 在一个背景中同时出现两个一样的人

对每个异常输出: {"type","timestamp","severity":"high/medium/low","desc"}
无异常返回空数组。
```

### 异常区间细化 (按需,不是默认)
若上一步给出的疑似异常可能是因网格抽帧只截到镜头切换瞬间(例如只看到物体的一半、被遮挡的肢体等),或者因为将这里的主体错认为其他主体了，必须对该时间区间用 `grid-generate --time_range "Ts-Te" --interval 0.5 --cols 5` 抽取`grid-small_batch.jpg` ~20 帧重判,确认是真异常还是抽帧误差。

### 判分
- 无异常 → **1**
- 单个 medium，而且这里能够明显的认出 → **0.5**
- 有 high 异常,或 medium ≥ 2 → **0**

## O7 · 剧情连贯

纯文本判定,只读 `overview.json`:

```
剧情概要: {{synopsis}}
时间线: {{timeline}}

评估:
1. 是否有完整起承转合?
2. 是否有让观众困惑的逻辑跳跃?列出位置。
3. 节奏是否合理 (有无大段重复 / 突然结束)?
4. 是否出现完全重复的片段或完全重复的台词?
```

### 判分
- 完整起承转合,无逻辑跳跃,节奏合理 → **1**
- 1-2 处轻微跳跃 / 局部节奏拖沓 → **0.5**
- 起承转合缺失 / 大段重复 / 完全重复台词 / 突然结束 → **0** (剧情垮了不可挽回)

## O8 · 音画同步

**单次 vision-understanding 调用**(原生支持视频含音频)+ ffprobe 兜底。

### 主调用

```
vision-understanding(final.mp4, prompt)
```

```
请同时听这段视频的音频、看其画面节奏,判断**音画同步**:

1. **旁白-画面对齐**: 旁白说到关键内容时,画面是否在表现对应内容? 是否有"旁白讲 A,画面演 B" 的脱节段落?
输出 JSON: {
  "narration_visual_alignment": 0/0.5/1,
  "lip_sync": 0/0.5/1 | null,        // 若无说话人特写填 null
  "rhythm_match": 0/0.5/1,
  "issues": [{"t_sec": 12.3, "type": "...", "desc": "..."}],
  "overall": 0/0.5/1
}
```

### ffprobe 兜底
- 无音轨 → O8 直接判 **0** (硬卡)
- 音频时长 vs 视频时长 abs diff ≥ 3s → 至少 **0.5**

## 通用注意

- **反馈只写负面**: 满分项 `反馈` 留空,扣分项必须指出具体问题(带时间戳/shot 编号最佳)。
- **cache 复用**: 同一 case 重跑时,已有 cache 文件直接跳过预处理。
- **粗看→精看**: 任何 atom 在某区间发现可疑,都可用 `grid-generate --time_range` 二次细抽帧确认(参考 SKILL.md 原则段)。

#### 音频一致性和音画同步的区别

两者容易混淆，但判定的维度完全不同：

**音频一致性** 关注音频自身的内在质量 —— 不问"音频和画面对齐了没"，只问"这段音频本身听起来对不对"：
- 同一角色前后音色是否一致（人声突然变粗/变细/变老/变性）
- BGM 风格是否贴合场景情绪（婚礼放哀乐、战斗场景放轻音乐等明显违和）
- BGM 是否有突兀的切换或断裂（同一场景内音乐风格突变、音量忽大忽小）
- 人声是否有异常（爆音、破音、电流声、突然消失、底噪突变）
- 人声音频是否清晰
**音画同步 (O8)** 关注音频与视频的时间对齐关系 —— 不问"音频好不好听"，只问"声音和画面在时间轴上对上了没"：
- 旁白说到"一只猫"时画面是否确实在展示猫（而非说到猫却播着狗的镜头）
- 镜头切换的节奏是否卡在旁白/BGM 的节拍上
- 音频已切到下一段但画面还停留在前一段（或反之）
- 是否存在大段静音 (> 3s 且不在场景过渡)?
**典型区分案例**：
| 场景 | 属于 | 原因 |
|------|------|------|
| 旁白从男声突然变成女声 | 音频一致性 | 声音自身不连续，与画面无关 |
| 激斗场景配了舒缓摇篮曲 | 音频一致性 | 音频内在气质与场景不匹配 |
| 音频大段没有声音 | 音画同步 | 这里和音频是否产生无关，主要是音频的连续性 |
| 旁白说"日落"时画面是天亮 | O8 音画同步 | 时间轴对齐错误，音频本身没问题 |
| BGM 在第 5 秒突然断掉换了一首 | 音频一致性 | 音频自身的断裂，非时间对齐问题 |
