# Skill Optimizer

## 目标

当一个已完成任务需要优化以下任一对象时，使用本技能：

1. 面向具体下游视频生成任务的 `video-skill`。
2. 根据任务输入和描述创建这些 `video-skill` 的 `video-skill-creator`。

本技能的目标是从任务失败或低分中定位根因，先将可执行修复沉淀到具体 `video-skill`，再将可泛化经验反向传播到 `video-skill-creator`，从而同时提升当前任务执行质量和未来 skill 创建质量。

## 必需输入

使用本技能时，需要收集并检查以下上下文：

1. **Creator skill 目录**：通常是 `video-skill-creator`。
2. **具体 skill 目录**：由 creator 创建出来的任务型 `video-skill`。
3. **任务输入**：原始下游任务需求、描述和约束。
4. **执行证据**：ReAct 过程、工具调用记录、生成产物、日志和最终输出。
5. **评估信号**：rubric 分数和反馈。如果没有 rubric，只有任务目标，则根据目标自行判断主要质量缺口。

## 核心流程

1. **诊断根因**
   - 找出低分 rubric、失败需求或执行错误。
   - 将问题追溯到缺失指令、工作流不清晰、creator 规则不足、参考知识缺失或工具/脚本限制。

2. **反向传播**
   - 先传播到具体 `video-skill`：分析 error 或低分 rubric 在执行层面为什么发生，判断具体 `video-skill` 是否缺少直接步骤、检查点、工具调用顺序、素材要求、镜头约束或失败规避规则。如果缺失，应先把修复写入具体 `video-skill`，让当前下游任务类型能被更直接地执行。
   - 再传播到 `video-skill-creator`：从具体 `video-skill` 的缺陷中抽象出 creator 层面的创建问题，判断 `video-skill-creator` 是否缺少某种任务分析方法、skill 结构要求、质量检查规则或参考知识使用原则。如果缺失，应将其写成 high-level 但可执行的 creator 规则，避免未来生成的 `video-skill` 再次缺少同类能力。
   - 不要跳过第一步直接修改 creator；也不要只修补具体 `video-skill` 而忽略 creator 是否需要学习同类错误。

3. **精简修改**
   - 只在合适的位置修改 `SKILL.md`、相关 `references/*.md` 或脚本。
   - 将每个失败转化为能够阻止同类失败的最小可复用规则；规则应足够具体，让未来 agent 真正会执行。
   - 更新前先检查目标 skill 中是否已经存在相同或高度相似的规则。如果已有规则覆盖该问题，应优先合并、改写或补充例子，而不是在多个位置重复强调同一个要点。
   - 避免因为多个 case 指向同一根因，就不断追加措辞相近的规则；应将其沉淀为一条更清晰、更强的规则。
   - 优先加强现有组织结构，而不是添加零散附录；如果领域细节会让主流程臃肿，应放入 references。

## 优化目标差异

### 具体 `video-skill`

`video-skill` 是根据某个任务输入和描述创建出来的执行型 skill。它的目标是帮助 agent 更直接、更稳定地完成该下游任务。

可以写得具体、直接、操作化，例如：

- 必需素材、镜头、prompt、文件名和最终交付物。
- 明确工作流步骤、工具调用顺序、验证检查点和重试条件。
- 当前任务相关的一致性约束、画面要求和失败规避策略。

当信息来自下游任务本身，且具体性能够避免重复失败时，不要过度抽象具体 `video-skill` 的执行指导；可以明确写出交付物、场景结构、prompt、素材和任务专属检查项。
### `video-skill-creator`

`video-skill-creator` 是生成型 skill。它的目标是根据未来不同任务的输入和描述，创建更好的任务型 `video-skill`。

更新应保持 high-level，但必须可执行，例如：

- 通用创建原则。
- 告诉 creator 应检查什么、判断什么、写入什么的具体 instructions。
- 展示如何把任务约束转化为执行指导的 cases 和 anti-cases。
- 判断生成出的 `video-skill` 是否足够具体的质量检查规则。

不要把当前任务的固定元素、角色、场景名、镜头编号或文件名硬编码进 `video-skill-creator`。

- 错误示例：在第 2 个镜头里记得加入猫。
- 正确示例：为每个生成镜头显式重申持续主体的关键属性，并检查其是否与全局角色设定保持一致。

## 视频生成相关领域知识
优化视频生成相关 skill 时，编辑前必须读取视频生成相关的领域参考：
- 主参考：`video-skill-creator/references/video_generation_expertise.md`
- 补充参考：`skill-optimizer/references/video_generation_expertise.md`（如果存在）
使用这些参考来确保优化符合视频生成最佳实践。
## 最终回复
完成分析与修改后，向用户报告：
1. **诊断摘要**：任务证据或评估中发现的根本原因。
2. **提炼规则**：新增或澄清的可复用优化规则。
3. **修改文件**：每个修改过的文件及其改动内容。
4. **执行确认**：说明是否遵循了反向传播和精简修改规则。
