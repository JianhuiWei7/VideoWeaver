01 — THE BOTTLENECK & THE IDEA

Long videos need more than a single model call.

Long video generation requires planning, tool orchestration, and consistency across many clips. Static, human-crafted workflows are costly to build and difficult to adapt. Refining one output at a time also leaves an opportunity unexplored: turning execution experience into skills that help on the next task.

THE IDEA

Give a general-purpose agent reusable foundation skills. Let it construct its own workflow, then improve that workflow through evidence-grounded feedback.

VideoWeaver combines an agent harness, a multimodal benchmark, and a skill evolution algorithm. We study this setting across OpenClaw, Claude Code, and Codex, with multiple backbone models.

01 / TASK INFERENCE

Build the workflow, then execute it.

The execution agent creates category-level composition skills and invokes foundation skills to generate videos. Each run produces execution traces, intermediate artifacts, and final outputs for evaluation.

A judge that looks beyond the final frame.

The evaluator gathers evidence from task inputs, tool calls, logs, intermediate files, audio, and video. It scores process and output quality and provides feedback for skill evolution.

03 — THE BENCHMARK

One instruction. Many ways to make a video.

285benchmark cases
16task categories
4input modalities

The benchmark spans avatar videos, animation, product demos, cinematic videos, teaching, audio-driven storytelling, and editing. Cases use text, image, audio, video, and combined references.

Text, image, audio, and video can also be combined as references. Testing includes held-out cases and three held-out task categories.
